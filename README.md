# 🧠 Statistics Calculator (v5) — Cyberpunk Holographic Terminal Edition

A high-performance Cyberpunk-themed Statistical Desktop Suite built with Python, Tkinter, NumPy, SciPy, and Matplotlib. Developed by **Abdelrhman Ramdan Kasem** (Horus University — Egypt).

---

## ✨ Features & Updates (v5)
* **Cyberpunk Holographic Interface:** Dark terminal theme with dynamic neon glowing borders, scanlines, and status indicators.
* **Smart Problem Parser & AI Integration:** Auto-extracts statistical parameters directly from pasted word problems or via Claude API.
* **Interactive Data Visualization:** Real-time plot generation using Matplotlib displaying acceptance/rejection regions, confidence bounds, and critical values.
* **Comprehensive Statistical Modules:**
  * Normal Distribution calculations ($P(a < X < b)$, $P(X < a)$, $P(X > a)$)
  * Sampling Distributions ($\hat{p}$ and $s^2$ Chi-Square)
  * Confidence Intervals ($\mu$, $P$, and $\sigma^2$)
  * Hypothesis Testing ($\mu$, $P$, and $\sigma^2$ with full step-by-step resolution)
* **Built-in Utilities:** Integrated Formula Sheets, Critical Value Tables ($Z$, $t$, $\chi^2$), and Calculation History export.

---

## 🛠️ Built With
* **Language:** Python 3.x
* **GUI:** `tkinter`, `ttk`
* **Math & Stats Engine:** `numpy`, `scipy.stats`
* **Plotting & Graphics:** `matplotlib`
